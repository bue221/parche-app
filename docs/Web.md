# Web

Código: [`apps/web`](../apps/web).

## Stack

Next.js 16 · React 19 · Tailwind 4 · TypeScript · pnpm.

Landing, explorar, fichas de evento/artista (ISR), legal, SEO.

## Comandos

```bash
cd apps/web
pnpm install
pnpm dev
pnpm build
pnpm lint
```

## Env

Copia `apps/web/.env.example`. Claves: `NEXT_PUBLIC_SITE_URL`, `API_URL`, `MEDIA_HOSTS`, store URLs, `NEXT_PUBLIC_APP_WEB_URL`.
