# App móvil

Código: [`apps/mobile`](../apps/mobile).

## Stack

Expo 57 · Expo Router · React Native 0.86 · NativeWind · TypeScript · pnpm.

## Comandos

```bash
cd apps/mobile
pnpm install
pnpm start          # Expo
pnpm lint
pnpm typecheck
pnpm test
pnpm web            # Expo web ~8081
```

## Env

`apps/mobile/.env.example` → `EXPO_PUBLIC_API_URL=http://localhost:8080`
