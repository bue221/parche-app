# Estado del arte

Referentes citados en el documento de Prácticas IV (útil para benchmarking; no son dependencias del monorepo).

## Plataformas de referencia

| Plataforma | Rol para Parche |
|------------|-----------------|
| [Resident Advisor](https://ra.co) | Agenda global, reviews, tiquetes — referente de industria. |
| [Dice](https://dice.fm) | Tiquetería anti-reventa, UX de “mis tickets”. |
| [Boiler Room](https://boilerroom.tv) | Streaming / comunidad underground. |
| [Xceed](https://www.xceed.me) | Unificación de clubes/eventos/artistas en Europa — modelo de profesionalización. |
| Techno Experience Magazine | Visibilidad de talento y cobertura cultural. |
| [DNA Music](https://dnamusic.edu.co) | Formación y divulgación techno en Colombia. |
| Clubbing Spain | Centralización de agenda/noticias en España. |

## Lectura de producto

Parche se inspira en la **unificación** (Xceed/RA) y en la **confianza de tiquetes** (Dice), adaptado a la escena bogotana/LatAm: menos informalidad, más herramienta para emergentes y puerta segura (QR).
